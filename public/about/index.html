دربارهٔ نبض فردا

سامانهٔ کاملاً استاتیک برای پوشش فارسی اخبار روز دنیای هوش مصنوعی، تکنولوژی و بازی.

این سیستم چیست؟

نبض فردا هر شب حدود بیست‌وشش فید انگلیسی را جمع می‌کند، خبرها را دسته‌بندی و رتبه‌بندی می‌کند، تیتر و خلاصه و متن فارسی می‌نویسد، صفحات HTML و تصاویر Open Graph می‌سازد، و همان پوشهٔ public/ را روی Vercel منتشر می‌کند. سرور اپلیکیشن یا دیتابیس وجود ندارد.

زمان‌بندی

  • ۰۰:۰۰ تهران — نسخهٔ شبانهٔ کامل (Fetch → Translate → Build → Deploy → Telegram → Instagram)
  • هر ۳ ساعت — به‌روزرسانی نوار استوری خبرهای داغ بدون بازسازی کل سایت

For judges (EN)

Nabz-e Farda is a fully static Persian news automation project: nightly edition at 00:00 Asia/Tehran, stories bar every 3 hours, multi-channel publish (web / Telegram / Instagram), Open Graph cards, RSS, sitemaps, PWA shell, and a public static JSON API. Start at the automation dashboard, then open an article and the API docs.
