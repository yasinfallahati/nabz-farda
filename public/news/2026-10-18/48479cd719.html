DeepSeek رابط‌های Search و Fetch را برای عامل‌ها عرضه کرد

DeepSeek search and fetch – $0.75 per 1000 successful requests

Hacker Newsیکشنبه ۲۶ مهر ۱۴۰۵، ساعت ۱۰:۲۰۱ دقیقه مطالعه

خلاصه

DeepSeek دو API تازه برای جست‌وجو و خواندن صفحات وب معرفی کرده که به ازای هر ۱۰۰۰ درخواست موفق ۰٫۷۵ دلار هزینه دارد؛ فراخوانی از طریق Claude Code و Codex تا ۱ نوامبر رایگان است.

خبر کامل

DeepSeek دو رابط برنامه‌نویسی تازه به نام‌های Search API و Fetch API منتشر کرده که به عامل‌های هوش مصنوعی و اپلیکیشن‌های RAG دسترسی به محتوای زندهٔ وب می‌دهند. هر دو APIهای JSON خام هستند و با همان کلید و احراز هویت API اصلی DeepSeek کار می‌کنند.

قیمت‌گذاری بر اساس درخواست است، نه توکن: هر ۱۰۰۰ درخواست موفق ۰٫۷۵ دلار. فقط درخواستی هزینه دارد که کد ۲۰۰ برگرداند و نتیجه داشته باشد؛ یعنی جست‌وجوی بی‌نتیجه، خطا و تایم‌اوت رایگان است و تعداد نتایج برگشتی هم روی قیمت اثری ندارد.

طبق مستندات، وقتی از DeepSeek از طریق DeepSeek Harness، Claude Code یا Codex استفاده می‌شود، فراخوانی‌های سمت سرور این ابزارها فعلاً رایگان است و صدور صورت‌حساب از ساعت ۰۰:۰۰ به وقت پکن در ۱ نوامبر ۲۰۲۶ شروع می‌شود. محدودیت تعداد درخواست در ثانیه هم برای هر حساب و جدا برای Search و Fetch اعمال می‌شود.
