اختلال در GitHub Actions، GitHub Pages و Webhooks

Degraded availability for GitHub Actions, GitHub Pages and Webhooks

Hacker Newsدوشنبه ۲۷ مهر ۱۴۰۵، ساعت ۱۹:۲۲۱ دقیقه مطالعه

خلاصه

صفحهٔ وضعیت GitHub از کاهش دسترس‌پذیری سرویس‌های Actions، Pages و Webhooks خبر داد؛ اختلالی که روی پایپ‌لاین‌ها و دیپلوی‌های بسیاری اثر گذاشت.

خبر کامل

GitHub در صفحهٔ وضعیت سرویس‌های خود یک رخداد با عنوان «کاهش دسترس‌پذیری GitHub Actions، GitHub Pages و Webhooks» ثبت کرده است.

این سه سرویس پایهٔ بسیاری از پایپ‌لاین‌های CI/CD، انتشار سایت‌های استاتیک و یکپارچه‌سازی‌های خودکار هستند و اختلال در آن‌ها می‌تواند اجرای تست‌ها، دیپلوی‌ها و اعلان‌ها را برای تیم‌های زیادی متوقف یا کند کند.

این خبر در Hacker News هم مورد توجه قرار گرفت و کاربران از تأثیر آن روی کارهای خودکارشان گفتند.

جزئیات و آخرین وضعیت رفع مشکل در صفحهٔ githubstatus.com منتشر می‌شود.
