## ۱) مشکل (≈۴۵ث)

**اسلاید:** «اخبار جهانی AI/Tech/Game — به فارسی، به‌موقع، بدون تیم خبری ۲۴ساعته»

**سخن:**
- مخاطب فارسی‌زبان به اخبار روز دنیای هوش مصنوعی و تکنولوژی نیاز دارد، اما منابع اصلی انگلیسی‌اند.
- پوشش دستی کند و ناپایدار است؛ انتشار چندکاناله (سایت + شبکه‌های اجتماعی) هزینهٔ عملیاتی بالا دارد.
- برای یک محصول رقابتی، باید **اتوماتیک، شفاف، و ارزان** باشد.

**English cue:** *Global AI/tech/gaming news → Persian, on schedule, without a 24/7 newsroom.*

---

## ۲) راه‌حل (≈۴۵ث)

**اسلاید:** «نبض فردا = سامانهٔ کاملاً استاتیک اتوماسیون اخبار»

**سخن:**
- هر شب فیدهای انگلیسی جمع می‌شوند، دسته‌بندی و رتبه‌بندی می‌شوند، تیتر/خلاصه/متن فارسی ساخته می‌شود، و همان پوشهٔ `public/` روی Vercel منتشر می‌شود.
- **بدون سرور اپلیکیشن و بدون دیتابیس.** خروجی فایل‌های استاتیک است که داور می‌تواند مستقیم ببیند و `curl` کند.

**یک‌خطی:** *RSS → ترجمه → سایت استاتیک → وب / تلگرام / اینستاگرام.*

---

## ۳) معماری (≈۹۰ث)

**اسلاید:** بلوک‌ها: Feeds → Fetch → Translate → Build/SEO → Deploy → Publish

**سخن:**
- حدود ۲۶ فید RSS (AI / Tech / Gaming).
- `fetch_news.py` جمع‌آوری، حذف تکراری، دسته‌بندی، رتبه‌بندی.
- `translate.py` تیتر، خلاصه، و بدنهٔ فارسی.
- `build.py` + `sitegen.py` صفحات مقاله، OG، نقشه سایت، RSS، ایندکس جست‌وجو، `ops.json`.
- Deploy با CLI روی پروژهٔ Vercel `nabz-farda`.
- Publish: تلگرام + دارایی‌های اینستاگرام از همان دادهٔ روز.

**نکته برای داور:** همهٔ artifactها داخل `public/` قابل بررسی‌اند.

---

## ۴) پایپ‌لاین شبانه و ۳ساعته (≈۹۰ث)

**اسلاید دو ستونه**

| شبانه (۰۰:۰۰ تهران) | هر ۳ ساعت |
|---|---|
| نسخهٔ کامل روز | فقط نوار استوری |
| Fetch → Translate → Build → Deploy → Telegram → Instagram | `update_stories.py` → deploy سبک |
| آرشیو روز جدید | حداکثر ۱۵ استوری زنده، انقضای ۲۴ساعته در مرورگر |

**سخن:** دو ریتم — «نسخهٔ روزنامه» در نیمه‌شب و «نبض شکستن خبر» در طول روز، بدون تداخل در همان اسلات ۰۰:۰۰.

---

## ۵) کانال‌ها: وب / اینستا / تلگرام (≈۹۰ث)

**اسلاید:** سه کارت

1. **وب** — RTL، سئو، PWA، جست‌وجو، خلاصه + خبر کامل  
2. **تلگرام** — پست‌های عکس با OG + لینک مقاله و منبع؛ هشدار استوری  
3. **اینستاگرام** — ریل، کارousel، استوری از همان داده (ابزار آفلاین/مرورگر)

**سخن:** یک منبع حقیقت؛ چند خروجی. اشتراک‌گذاری در سایت بدون SDK ردیابی شخص ثالث.

---

## ۶) قابلیت‌های سایت (≈۹۰ث)

**چک‌لیست اسلاید (فارسی):**
- صفحات مقالهٔ استاتیک + JSON-LD + OG با شکل‌دهی صحیح فارسی  
- نوار استوری شبه‌اینستاگرام  
- چیپ دسته‌ها + `/search/` روی `search-index.json`  
- PWA (مانیفست + SW + آفلاین فارسی)  
- صفحهٔ درباره برای داوران  

**(اختیاری روی اسلاید دوم)** خواندن زمان، اشتراک تلگرام/X/کپی لینک، مقالات مرتبط.

---

## ۷) اتوماسیون (≈۶۰ث)

**اسلاید / لایو:** https://nabz-farda.vercel.app/automation/

**سخن:** داشبورد مراحل پایپ‌لاین + آمار زنده از `/data/ops.json` (تاریخ شبانه، تعداد دسته، استوری، تلگرام، فیدها، commit، زمان ساخت). شفافیت عملیاتی برای داور — بدون پنل ادمین سنگین.

---

## ۸) دمو زنده (≈۹۰ث)

**اسکریپت کلیک:**
1. خانه — استوری‌ها، چیپ‌ها، یک کارت را باز کن.  
2. مقاله — خلاصه / خبر کامل، زمان مطالعه، اشتراک، مرتبط.  
3. `/automation/` — اعداد زنده را نشان بده.  
4. (اختیاری) `/about/` یا `/search/`.

**پشتیبان اگر اینترنت ضعیف بود:** اسکرین‌شات‌های محلی + `curl` روی `ops.json`.

```bash
curl -s https://nabz-farda.vercel.app/data/ops.json | head
```
